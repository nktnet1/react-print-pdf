## Why?

<Callout intent="note" title="React Print outputs HTML">
  React Print helps you design printable documents with React. The `compile`
  function returns an HTML string and print styles that you can pass to the PDF
  renderer or print workflow of your choice.
</Callout>

React Print provides reusable components for document layouts that are awkward to maintain with ad-hoc HTML: page headers and footers, page breaks, running values, footnotes, Markdown, LaTeX, Tailwind CSS, and more.

## Getting Started

React Print is designed to be incrementally adopted, so you can add it to an existing React or TypeScript project without adopting a hosted document platform.

<Callout intent="launch" title="React Print">
  Build the document in React, compile it to HTML, then choose the PDF renderer
  that fits your application.
</Callout>

<Card title="Set up" icon={<HammerIcon />} href="/docs/getting-started/setup">
  Install the package and compile your first printable document.
</Card>

## Rendering

React Print deliberately stops at renderer-ready HTML. You can render that HTML with a local browser print pipeline, a paged-media engine, or another PDF renderer depending on the CSS features and deployment model your application needs.
