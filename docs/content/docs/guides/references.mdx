---
title: "References"
description: "Create internal links and printed page references in a document."
---

Printable HTML can use normal fragment links for cross-references between sections of a document.

## Link to a section

Give the destination an `id` and link to it with a fragment URL:

```jsx
<a href="#appendix">Jump to the appendix</a>

<section id="appendix">
  <h2>Appendix</h2>
</section>
```

Whether the fragment becomes a clickable PDF link depends on the PDF renderer you use.

## Printed page references

Paged-media engines that support generated-content functions can also show the page number of a referenced element. For example:

```html
<a class="page-reference" href="#appendix">Appendix</a>
```

```css
.page-reference::after {
  content: " (page " target-counter(attr(href), page) ")";
}
```

Support for `target-counter()` varies between rendering engines, so check the renderer's paged-media support before relying on it.
