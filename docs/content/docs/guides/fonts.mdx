---
title: "Fonts"
description: "Configure hosted and local fonts for printable React documents."
---

Fonts work the same way as they do in HTML and CSS, subject to the capabilities of the renderer you choose.

## Hosted Webfont

You can add a link to a hosted webfont stylesheet, such as Google Fonts, Adobe Fonts, or a stylesheet you host yourself.

<Tabs>
<Tab title="HTML">
```html
<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Roboto&display=swap">
</head>
<body style="font-family: Roboto, sans-serif">
  <p>Some text</p>
</body>
</html>
```
</Tab>
<Tab title="React">
```jsx
const Document = () => {
  return (
    <>
      <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Roboto&display=swap" />
      <p style={{ fontFamily: "Roboto, sans-serif" }}>Some text</p>
    </>
  );
};
```
</Tab>
</Tabs>

## Local Webfont

Local font files can be referenced with `@font-face`. Make the font available at the URL used by your compiled HTML, or embed it as a data URL if your renderer does not load sibling assets.

```css
@font-face {
  font-family: "Roboto";
  src: url("./Roboto-Regular.ttf") format("truetype");
  font-weight: 400;
  font-style: normal;
}

body {
  font-family: "Roboto", sans-serif;
}
```

When using a local renderer, keep the font next to the HTML or configure the renderer's base URL so relative asset paths resolve correctly.
