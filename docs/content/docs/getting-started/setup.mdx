# Set Up

## 1. Create a project

Create a new folder and initialize an npm project, or use an existing React application.

```sh
mkdir react-print-starter
cd react-print-starter
npm init -y
npm pkg set type=module
```

## 2. Install the package

In an existing React application, install React Print PDF; it uses your application's React and React DOM peers (React 18.3.1+ or React 19).

<CodeBlocks>

```sh title="npm"
npm install react-print-pdf
```

```sh title="yarn"
yarn add react-print-pdf
```

```sh title="pnpm"
pnpm add react-print-pdf
```

</CodeBlocks>

For the empty Node.js project created in step 1, install React and a runner for the TSX files used below:

```sh
npm install react-print-pdf react@^19 react-dom@^19
npm install --save-dev tsx typescript @types/react @types/react-dom
```

## 3. Create your first document component

Create `document/index.tsx`:

```tsx title="document/index.tsx"
import React from "react";
import { PageBreak } from "react-print-pdf";

export const Document = () => (
  <main>
    <h1>Quarterly report</h1>
    <p>This appears on the first page.</p>
    <PageBreak />
    <h2>Appendix</h2>
    <p>This appears on the next page.</p>
  </main>
);
```

## 4. Compile the document to HTML

Create `render.tsx` to compile the document:

```tsx
import React from "react";
import { compile } from "react-print-pdf";
import { Document } from "./document";

const html = await compile(<Document />);

console.log(html);
```

Run the example with `npx tsx render.tsx`.

## 5. Render the HTML

`compile()` returns renderer-ready HTML. Save it, send it to a print pipeline, or pass it to a PDF renderer that supports the CSS features your document uses. React Print PDF does not require a hosted rendering service. Page breaks are widely supported, but advanced running headers, footers, and automatic footnotes depend on the chosen renderer. In particular, Chromium (including the Playwright and Gotenberg integrations) does not support the paged-media CSS features those components use.

## Using components directly in a browser

If you are mounting printable components in a React app **without** using `compile()`, import their extracted print styles once in your browser entrypoint:

```tsx
import "react-print-pdf/dist/index.css";
import { PageBreak } from "react-print-pdf/client";
```

The `compile()` helper already embeds those print styles, so this extra import is only for direct rendering.
