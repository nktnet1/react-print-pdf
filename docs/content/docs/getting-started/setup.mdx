# Set Up

## 1. Create a project

Create a new folder and initialize an npm project, or use an existing React application.

```sh
mkdir react-print-starter
cd react-print-starter
npm init -y
```

## 2. Install the package

<CodeBlocks>

```sh title="npm"
npm install react-print-pdf
```

```sh title="yarn"
yarn add react-print-pdf
```

```sh title="pnpm"
pnpm add react-print-pdf
```

</CodeBlocks>

## 3. Create your first document component

Create `document/index.tsx`:

```tsx title="document/index.tsx"
import { PageBottom, PageBreak, PageTop } from "react-print-pdf";

export const Document = () => {
  return (
    <div>
      <PageTop>
        <span>Hello #1</span>
      </PageTop>
      <div>Hello #2</div>
      <PageBottom>
        <div>Hello #3</div>
      </PageBottom>
      <PageBreak />
      <span>Hello #4, but on a new page!</span>
    </div>
  );
};
```

## 4. Compile the document to HTML

Create an entry file that renders the document with `compile`:

```tsx
import { compile } from "react-print-pdf";
import { Document } from "./document";

const html = await compile(<Document />);

console.log(html);
```

## 5. Render the HTML

`compile()` returns renderer-ready HTML. Save it, send it to a print pipeline, or pass it to a PDF renderer that supports the CSS features your document uses. React Print PDF does not require a hosted rendering service.
