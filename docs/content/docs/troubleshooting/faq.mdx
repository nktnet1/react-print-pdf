## Issues with Node.js modules

Use the default `react-print-pdf` entrypoint in Node.js, SSR, and build-time document generation:

```ts
import { compile, PageBreak } from "react-print-pdf";
```

For browser-only usage, the explicit client entrypoint is also available:

```ts
import { PageBreak } from "react-print-pdf/client";
```

The package does not include or require a hosted server. `compile()` produces HTML locally in your application.
