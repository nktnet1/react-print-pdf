---
title: Tailwind
description: Use Tailwind CSS v4 utilities and CSS-first configuration in printable React documents.
---

`Tailwind` compiles the utility classes used by its children with Tailwind CSS v4. CSS-first configuration is supported through the `stylesheet` prop, while existing JavaScript `config` objects remain supported for backwards compatibility. When rendering on the server, use React Print's async `compile()` helper so Tailwind styles are resolved before the HTML is returned.

#### Tailwind v4 CSS configuration

Use Tailwind v4 directives such as `@theme`, `@utility`, and `@custom-variant` through the `stylesheet` prop.

#### Legacy JavaScript config

Existing JavaScript theme configuration remains supported through Tailwind v4's compatibility layer.

```jsx
import { Tailwind } from "@fileforge/react-print";

<Tailwind
  config={{
    theme: {
      extend: {
        colors: {
          primary: "#6484cf",
        },
      },
    },
  }}
>
  <div className="bg-primary p-12 rounded-2xl"></div>
</Tailwind>;
```

#### Disable Preflight

Set `preflight={false}` to omit Tailwind's Preflight reset while keeping utility classes available.
